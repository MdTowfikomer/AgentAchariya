# Agent Acharya — frontend

The whiteboard web app: voice class, live board, circle-to-ask, research
panel, chat history. Next.js on LiveKit.

```bash
cp .env.example .env.local   # LIVEKIT_URL, LIVEKIT_API_KEY, LIVEKIT_API_SECRET, AGENT_NAME=nova-te
pnpm install
pnpm dev                     # http://localhost:3002
```
